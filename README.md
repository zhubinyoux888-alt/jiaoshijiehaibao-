# 教师节卡片批量生成工作台

这是独立的教师节卡片批量生成版本，只包含“教师节卡片”模块。

## 使用方式

1. 双击 `start.command`，或直接打开 `index.html`。
2. 上传教师节卡片表格。
3. 上传讲师照片。
4. 点击“导出当前预览图片”或“批量导出所有图片”。

## 表格字段

表格建议包含以下列名：

- 讲师姓名
- 课程
- 感谢语
- 教师节祝福语
- 人物

照片会按“人物”或“讲师姓名”字段和文件名匹配。

## 运行说明

该版本不依赖 Sketch 软件，不需要启动后端服务。模板底图和叠加层已经内嵌到 `template-assets.js`，支持直接在浏览器本地生成并导出图片。
